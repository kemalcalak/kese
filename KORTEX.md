# kese

A personal-finance API: bank statements are imported, transactions are
categorised, budgets are watched, a month is reported. FastAPI over
PostgreSQL, async throughout.

The data here is synthetic. Statements are generated by this project's own
generator; a real bank statement never enters this repository.

# Commands

- Tests: `uv run pytest -q`
- Lint: `uv run ruff check . --fix` then `uv run ruff format .`
- Types: `uv run mypy`
- Database: `docker compose up -d` (PostgreSQL on port 5433)
- Migrations: `uv run alembic upgrade head`

A change is finished when the tests, the linter and the type checker are all
green. Run them; do not assume.

# Layout

```text
src/kese/
├── api/           FastAPI routers: a request in, a response out
├── services/      the business rules; no FastAPI and no SQL in here
├── repositories/  the SQLAlchemy queries; the only place a session is used
├── schemas/       Pydantic models for the wire
├── models/        SQLAlchemy ORM models
└── core/          settings, the engine and session, security
tests/
├── acceptance/    written by hand, and never edited
├── integration/   the API against a real database
└── unit/          services and rules, no database
```

A router calls a service. A service calls a repository. Nothing skips a
layer, and nothing calls back up.

# Conventions

- English everywhere: code, comments, docstrings, commit messages.
- Dependencies through `uv add`; never hand-edit `pyproject.toml`.
- Money is `Decimal` and `NUMERIC` in the database. Never a float.
- Datetimes are timezone-aware and stored in UTC.
- Settings come from `pydantic-settings` with the `KESE_` prefix. No secret
  is ever written in code, and `.env` is not committed.
- Every model change carries an Alembic migration in the same change.
- Every endpoint has a test.
- Type hints on every function; `mypy` runs in strict mode.
- Conventional Commits: `feat:`, `fix:`, `refactor:`, `test:`, `docs:`,
  `chore:`.

# Rules

- **`tests/acceptance/` is not yours.** Those tests state what a stage must
  do. Make them pass by changing the code under `src/`; never edit, skip,
  weaken or delete one.
- Never silence a check. No `# type: ignore`, no `# noqa`, no
  `pytest.mark.skip` to get to green.
- Nothing is attached to a terminal. Never start a server that does not
  return - no `uvicorn`, no `--reload`, no watch mode. The API is tested
  through httpx against the ASGI app, in process.
